# Simple Python Calculator

A console-based Python 3 calculator that performs basic arithmetic operations:
addition, subtraction, multiplication, and division.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Input validation to ensure numeric values
- Division by zero check

## Requirements

- Python 3.x

## Usage

1. Copy the code into a file named `calculator.py`.
2. Run the script:

```bash
python calculator.py
